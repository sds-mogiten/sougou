## 編集のしかた

数学の訂正サイト（errata）と同じです。`.md` ファイルを開いて鉛筆アイコンで編集し、「Commit changes」を押すと1分ほどで反映されます。

- 数式は `$...$`（インライン）と `$$...$$`（別行立て）で書けます（MathJax で表示）。
- 表・枠・図は HTML で書いてあります（`<table>`、`<div class="box">`、`<div class="ans">`、`<svg>`）。中の文字だけ書き換えれば大丈夫です。
- 訂正を載せるときは、問題文を直すのに加えて `errata.md` にも訂正内容を書いてください。
- `.html`・`style.css`・`app.js` は表示用の仕組みなので、基本的に触らなくてOKです。
