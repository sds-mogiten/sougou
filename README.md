# 総合問題 対策問題

一橋祭 SDS模擬店「三度の飯よりホットサンド」の配布特典「総合問題 対策問題」のPDFと訂正情報を置くサイトです。

公開URL: https://sds-mogiten.github.io/sougou/

| ページ | URL | ファイル |
|---|---|---|
| 目次 | https://sds-mogiten.github.io/sougou/ | `index.html` |
| 問題冊子 | https://sds-mogiten.github.io/sougou/mondai.pdf | `mondai.pdf` |
| 解答・解説 | https://sds-mogiten.github.io/sougou/kaitou.pdf | `kaitou.pdf` |
| 訂正情報 | https://sds-mogiten.github.io/sougou/errata | `errata.md` |

## 更新のしかた

- **PDFを差し替える**：「Add file」→「Upload files」で、同じファイル名（`mondai.pdf` / `kaitou.pdf`）のPDFをアップロードすると上書きされます。ファイル名を変えるとリンクが切れるので注意してください。
- **訂正情報**：数学の訂正サイト（errata）と同じです。`errata.md` を鉛筆アイコンで編集して「Commit changes」を押すと、1分ほどで反映されます。数式は `$...$` / `$$...$$` で書けます。
- `.html`・`style.css`・`app.js` は表示用の仕組みなので、基本的に触らなくてOKです。
